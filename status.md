# Project Status Tracker

## Development Milestones
- [x] **Color Tokenization**: Mapped 10 colors to CSS variables in `:root` inside `style.css`.
- [x] **Poppins Typography**: Imported Poppins and applied it to heading and body text.
- [x] **Clean Figma Vectors**: Removed Figma-specific header rectangle elements from `1_5.svg` and compiled.
- [x] **High-Performance Scroll Transitions**: Added mathematical scroll calculations centered on the cat's nose (Phase 1a) and mouth center (Phase 1b) running in a `requestAnimationFrame` loop.
- [x] **Material Design Ripples**: Added custom ripple effect span injection on CTA buttons on click.
- [x] **Git Repository Setup**: Initialized Git repository and set up a status tracking dashboard.

## Live Dashboard & Dev Server
- Dev Server running on port `8000`.
- **View Dashboard**: Open [http://localhost:8000/status.html](http://localhost:8000/status.html) to see the live status tracker.
- **View Portfolio**: Open [http://localhost:8000/index.html](http://localhost:8000/index.html) to see the live landing page.

## Key Project Commands
- **Compile Layout**: `python3 build_landing_page.py`
- **Serve Locally**: `python3 server.py`
- **Git Status**: `git status`
